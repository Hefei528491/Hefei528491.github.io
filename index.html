域名 Domain

域名是网站在互联网上的名字，让人好记、好找。它背后对应一串 IP 地址（门牌号），电脑通过 DNS（互联网的电话本）把域名翻译成 IP，再找到那台服务器。从右往左看：顶级域名（如 .co）、主域名、子域名。把域名的 NS 记录改到某家服务商，就等于把解析权交给它托管。

进度：已注册 528491.hidns.co，并把 NS 委托到 Cloudflare 托管（2026-11-25）

VPS 云服务器

VPS（Virtual Private Server，虚拟专用服务器）是把一台物理服务器用虚拟化技术（如 KVM）切成多台互相独立的小服务器，每台有自己的操作系统、root 权限和 SSH 登录，可以自己装软件、跑服务。按月租用，通常是非托管的：系统维护和备份要自己负责。它和只能跑指定环境的托管沙盒不同，是一台真正能自己做主的云电脑。

进度：已了解概念，对比过 Vultr、DigitalOcean、RackNerd 等方案，还没正式开一台长期用

域名邮箱 Domain Email

域名邮箱就是用自己的域名做邮箱后缀。Cloudflare Email Routing 是免费的收信转发：MX 记录告诉发件方把信投到哪里，转发规则再把信转到已有的收件箱；回信时发件人还是原来的邮箱。2026 年 11 月起，Cloudflare 的 Email Sending 在 Workers 免费计划上也能用了，可以从域名地址发信给已验证的收件地址，适合提醒、通知类用途；发给任意收件人需要付费计划。

进度：已开通 uan@528491.hidns.co 收信转发（2026-11-25）；2026-11-26 又试通了用 uan@ 发信，收发都通了

DNS 与 Cloudflare

DNS 记录各管一件事：A/CNAME 决定网站指向哪台服务器，MX 决定邮件投递到哪里，TXT 常用来放 SPF、DKIM 这类验证信息。域名托管到 Cloudflare 后，解析、邮件路由、静态站点都能在一个地方管理。

进度：已完成 NS 切换、MX/SPF/DKIM 记录自动配置

API 接口

API（Application Programming Interface，应用程序编程接口）是程序和程序之间约定好的对话方式：人用服务靠网页界面，程序用服务靠 API。常见的 Web API 走 HTTP 协议，用端点网址、GET/POST 等方法和 JSON 参数发请求，服务器用状态码回复（200 成功、400 参数不对、403 权限不够、503 服务器忙）。API Key 是程序的身份证，绑定认证、权限和计费，只能走安全通道保管。

进度：已在用 Cloudflare、Gemini、xAI、Parallel 的 API，key 均经安全入口存入（2026-11-27 系统学完概念）
